# Oefenexamens Servicedesk B1-K2

Oefenexamens voor kerntaak B1-K2 van Medewerker ICT (Ter AA). Live: https://marcelteraa.github.io/servicedesk/

- `index.html`: startpagina met dag 1–4
- `examen.html?dag=N`: examenomgeving (inbox, registratie, antwoordmail, balie, naslag, inleveren als PDF)
- `data/dagen.js`: de meldingen per dag. Een nieuwe dag maak je door hier mails toe te voegen en `open: true` te zetten.
- `data/naslag.js`: de SLA, procedures, scripts, escalatiematrix en keuzelijsten

Uitwerkingen staan bewust **niet** in deze (openbare) repo.
