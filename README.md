# Oefenexamens Servicedesk B1-K2

Oefenexamens voor kerntaak B1-K2 van Medewerker ICT (Ter AA). Live: https://marcelteraa.github.io/servicedesk/

Opzet zoals de FirstLine-dagtaken: per dag een postvak (e-mails) en een balie. Studenten registreren in **TOPdesk**; de pagina geeft alleen de meldingen. Er zijn ook knoppen voor e-mailantwoorden (gekopieerd naar het klembord), "geregistreerd"-stempels en voortgang.

- `index.html`: de hele app (demo ½ dag + dag 1–6)
- `data/dagen.js`: de meldingen per dag. Een dag vul je met `mails` + `balie` en `open: true`.
- `examen.html`: stuurt door naar de startpagina (oude versie)

Uitwerkingen staan bewust **niet** in deze (openbare) repo.
